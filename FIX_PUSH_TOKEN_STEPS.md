# Fix Push Token for Darragh

## The Issue
The push token shows as "❌ Not Set" in the app because:
1. Push tokens are not persisted - they need to be regenerated each app launch
2. The token might not be getting generated due to permission issues

## Steps to Fix

### 1. Check iOS Settings
Go to **Settings > Notifications > CampusLink** and ensure:
- ✅ Allow Notifications is ON
- ✅ Alerts, Sounds, and Badges are enabled

### 2. In the App (PushNotificationTestView)

1. **First, tap "Request Permissions"** button
   - Even if you think permissions are granted, tap this to ensure the app requests them

2. **Force close and reopen the app**
   - Swipe up and remove CampusLink from app switcher
   - Open the app again
   - This triggers `registerForPushNotifications()` on app launch

3. **Go back to Push Notification Test**
   - You should now see "Push Token: ✅ Available"

4. **Tap "Save Token to Database"**
   - This saves your device token to Supabase

5. **Test with "Test Apple Push (Direct)"**
   - This should now work!

## If Still Not Working

### Check Console Logs (if running via Xcode)
Look for these log messages:
- `🔔 Registering for remote notifications...`
- `🔔 Successfully registered for remote notifications`
- `📱 Device token received`

### Try This SQL Query
Run this in Supabase Dashboard to check your token status:
```sql
SELECT 
  u.id,
  u.name,
  unp.push_enabled,
  unp.push_token,
  unp.push_platform,
  unp.updated_at,
  NOW() - unp.updated_at as time_since_update
FROM users u
LEFT JOIN user_notification_preferences unp ON unp.user_id = u.id
WHERE u.id = 'd4c8cd57-c182-4eed-a961-b24651061676';
```

## Why This Happens
- iOS requires explicit permission for push notifications
- Device tokens are generated by Apple after permission is granted
- Tokens expire and need to be refreshed periodically
- The app stores tokens in memory (`@Published var pushToken`) so they reset on app launch
- That's why we call `registerForPushNotifications()` on every app launch
