## Wallet Balance Fix - Real Stripe Balance

**Issue:** Wallet showing $10.75 but actual Stripe Connect balance is $0.01

**Root Cause:** 
- `walletService.ts` was reading balance from local `wallets` table (cached)
- This local table was out of sync with actual Stripe Connect account balance
- The `get-stripe-balance` edge function existed but wasn't being used

**Fix Applied:**

1. **Updated `getWalletBalance()`** - Now fetches real balance from Stripe:
   - Calls `get-stripe-balance` edge function
   - Returns actual Stripe `available_for_standard_cents` and `pending_cents`
   - Falls back to local wallet only for `escrow` info

2. **Added `getStripeBalance()` function** - New exported function to get Stripe balance directly

3. **Updated `requestPayout()`** - Now validates against real Stripe balance, not cached local wallet

4. **Fixed PayoutRequestScreen bug** - Was passing dollars to `requestPayout()` which expected cents. Added `Math.round(payoutAmount * 100)` conversion.

**Files Changed:**
- `mobile/src/services/walletService.ts` - Added `getStripeBalance()`, updated `getWalletBalance()` and `requestPayout()`
- `mobile/src/screens/wallet/PayoutRequestScreen.tsx` - Fixed dollars-to-cents conversion

**Result:** ✅ Wallet now displays real Stripe Connect balance as source of truth
