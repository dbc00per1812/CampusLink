# Development Log - January 20, 2026

## Splash Screen Fix

**Problem:** Splash screen getting stuck or endless loading indicator between splash and app.

**Root Causes Identified:**
1. Module-level `splashHidden` variable persisted across hot reloads, preventing splash from hiding
2. Race condition between navigation ready callback and loading state changes
3. No timeout on Supabase auth/profile calls - hangs indefinitely if network is slow
4. Failsafe only hid splash screen but didn't fix the loading indicator state

**Solution Applied (`RootNavigator.tsx`):**
- Moved `splashHidden` to a ref inside the component to prevent hot reload issues
- Added `withTimeout` helper to wrap auth calls with 5-second timeout
- Profile verification now has 3-second timeout (allows access on timeout since session is valid)
- Failsafe at 4 seconds now both hides splash AND sets ready state
- Proper `isMounted` cleanup to prevent state updates on unmounted components
- Simplified splash hiding logic with refs instead of module-level variables
- Added logging for debugging auth flow

## Offers System - Database Column Fix

**Problem:** Error "Could not find the 'buyer_id' column of 'offers' in the schema cache" when clicking "Send Offer" button.

**Root Cause:** The `offerService.ts` was using column names that don't exist in the actual database schema:
- `buyer_id` - doesn't exist in offers table
- `offer_amount` - should be `price_cents`
- `counter_amount`, `counter_message` - don't exist

**Database Schema (offers table):**
- `offer_from_user_id` - Person making the offer
- `offer_to_user_id` - Person receiving the offer  
- `seller_id` - Legacy field (kept for compatibility)
- `seeker_id` - Legacy field (for seek listings)
- `price_cents` - The offer amount in cents
- `listing_type` - 'seek' or 'regular'
- `parent_offer_id` - Links counter-offers

**Files Fixed:**

1. **`mobile/src/services/offerService.ts`:**
   - `createOffer`: Changed `buyer_id` → `offer_from_user_id`, `offer_amount` → `price_cents`
   - `getOffer`: Fixed join query to use `offer_from_user_id` and `offer_to_user_id`
   - `getOffersForListing`: Fixed join query
   - `acceptOffer/declineOffer`: Changed filter from `seller_id` → `offer_to_user_id`
   - `counterOffer`: Rewritten to create new offer with `parent_offer_id` (proper counter-offer flow)
   - `withdrawOffer`: Changed filter from `buyer_id` → `offer_from_user_id`
   - `getBuyerOffers/getSellerOffers`: Fixed queries to use correct columns

2. **`mobile/src/screens/offers/OffersScreen.tsx`:**
   - Fixed queries to use `offer_from_user_id`/`offer_to_user_id`
   - Fixed joined user data to use `offer_from`/`offer_to` instead of `buyer`/`seller`
   - Fixed display to use `price_cents` instead of `offer_amount`

3. **`mobile/src/screens/offers/OfferDetailScreen.tsx`:**
   - Fixed `isBuyer`/`isSeller` logic based on listing type
   - Fixed all `offer_amount` references to use `price_cents`
   - Fixed seller ID determination for order creation

4. **`mobile/src/types/product.ts`:**
   - Updated `Offer` interface to match actual database schema
   - Removed non-existent fields (`buyer_id`, `offer_amount`, `counter_amount`, `counter_message`)
   - Added proper joined data types (`offer_from`, `offer_to`)

## Messaging & Offers Broken - Database Trigger Column Mismatch

**Problem:** "Failed to send message" error with code `42703: column "full_name" does not exist`

**Root Cause:** Database triggers in `onesignal_notification_triggers.sql` referenced non-existent columns:
- `full_name` → should be `name`
- `username` → should be `name`
- `user1_id` / `user2_id` → should be `buyer_id` / `seller_id`
- `offer_amount` → should be `price_cents`
- `total_amount` → should be `price_cents`
- `rated_user_id` → should be `rated_id`
- `amount` → should be `amount_cents`

**Affected Triggers:**
1. `notify_new_message()` - Lines 63, 67-72
2. `notify_new_offer()` - Lines 114, 122
3. `notify_offer_status_change()` - Status handling
4. `notify_order_placed()` - Lines 220, 228
5. `notify_order_status_change()` - Line 281
6. `notify_payout_status()` - Line 371
7. `notify_new_rating()` - Lines 423, 433

**Files Fixed:**

1. **`docs/sql/onesignal_notification_triggers.sql`:**
   - All `COALESCE(full_name, username, 'Someone')` → `COALESCE(name, 'Someone')`

   - `NEW.offer_amount` → `NEW.price_cents`
   - `NEW.total_amount` → `NEW.price_cents`
   - `NEW.amount` → `NEW.amount_cents`
   - `NEW.rated_user_id` → `NEW.rated_id`
   - `NEW.buyer_id` (offers) → `NEW.offer_from_user_id`
