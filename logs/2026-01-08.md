## Supabase Storage Bucket Name Mismatch Fix

### Issue Identified
User reported "Bucket not found" error when uploading profile photo in React Native TestFlight build, while Swift iOS version worked correctly.

### Root Cause
Bucket name mismatch between React Native and Swift implementations:
- **Profile photos**: React Native used `'profile-pics'` but Swift used `"profile-pictures"` ✅
- **Order/delivery photos**: React Native used `'order-photos'` but Swift used `"delivery-photos"` ✅

### Changes Made
1. **File**: `mobile/src/services/imageUploadService.ts`
   - Fixed line 99: Changed `'profile-pics'` → `'profile-pictures'`

2. **File**: `mobile/src/screens/orders/OrderDetailScreen.tsx`
   - Fixed lines 186, 196: Changed `'order-photos'` → `'delivery-photos'`

### Status
✅ Fixed - React Native now uses same bucket names as Swift iOS version
