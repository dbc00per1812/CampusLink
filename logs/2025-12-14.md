### Technical Implementation Details

**Payment Flow Architecture:**
1. User clicks "Buy Now" on a listing
2. App calls `configurePaymentSheet(listingId)`
3. Service invokes edge function → creates PaymentIntent
4. Edge function checks seller's Stripe Connect status:
   - If active: Uses destination charges (money goes directly to seller)
   - If pending/missing: Uses escrow mode (money held by platform)
5. Service initializes PaymentSheet with client secret
6. App calls `presentStripePaymentSheet()`
7. User completes payment in Stripe's UI
8. On success: App creates order record
9. Order service handles escrow/wallet deduction

**Payment Methods Supported:**
- Credit/debit cards (via Stripe Elements)
- Apple Pay (iOS with merchant identifier)
- Google Pay (Android)
- Link (Stripe's 1-click checkout)

**Security:**
- Client secret is single-use and expires after payment
- Payment intent uses manual capture (required for escrow)
- All sensitive operations happen server-side in edge function
- Publishable key is safe to expose in client app

**Stripe Connect Integration:**
The edge function intelligently handles seller onboarding status:
- **Transfers capability = active**: Direct destination charges to seller
- **No Connect account**: Escrow mode, seller must complete onboarding to receive funds
- **Connect account pending**: Escrow mode until verification complete
- This allows listings before seller completes Connect setup (deferred onboarding)

**Pricing Transparency:**
The service returns full pricing breakdown for UI display:
- `seller_price_cents`: What the seller listed the item for
- `stripe_fee_cents`: Stripe's 2.9% + $0.30 processing fee
- `buyer_price_cents`: Total the buyer pays (seller price + Stripe fee)
- `campuslink_cut_cents`: Platform fee (currently $0)
- `application_fee_cents`: Fee taken from transaction (covers Stripe only)
- `seller_receives_cents`: Net amount seller gets (equals listing price)

**No Platform Fee:**
CampusLink currently operates with zero platform fees:
- Buyers pay exact listing price + Stripe's processing fee
- Sellers receive their full listing price
- Platform covers Stripe fees from application fee
- This is configured in the edge function, not client-side

    setIsLoadingConversation(false);
  }
};
