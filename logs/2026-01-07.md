# 2026-01-07 - Snapchat Sharing Fix

## Issue
Post sharing to Snapchat was saving sticker to camera roll instead of automatically opening Snapchat with the sticker in the picture frame like Reddit does.

## Root Cause Analysis
After deep research, found multiple issues:

1. **The `@snapchat/snap-kit-react-native` SDK (v0.4.0) has bugs**
   - The native `createSnapSticker` function uses `[NSData dataWithContentsOfURL:url]` which often fails to load React Native file paths
   - The SDK is outdated - Snapchat now recommends "code-only" Creative Kit without SDK

2. **Snapchat deprecated SDK-based Creative Kit**
   - Their docs now state: "Creative Kit does not require the installation of any SDKs"

3. **Many apps successfully use Creative Kit**
   - Netflix, Disney+, Spotify, Strava, Ticketmaster, GoFundMe all have working integrations
   - This confirms it IS possible for third-party apps

## Solution Implemented
Replaced `@snapchat/snap-kit-react-native` with `react-native-share` library which:
- Has proper, actively maintained Snapchat Creative Kit integration
- Uses the correct native pasteboard approach
- Supports sticker sharing with attachment URLs

## Changes Made

### 1. Package Installation
- Added `react-native-share` package

### 2. ShareListingSheet.tsx
- Replaced `@snapchat/snap-kit-react-native` with `react-native-share`
- Updated `shareToSnapchat` to use `RNShare.shareSingle()` with `Social.Snapchat`
- Updated `shareToInstagram` to use `RNShare.shareSingle()` with `Social.InstagramStories`
- Proper base64 image handling for both platforms
- Better error handling with fallback to camera roll method

### 3. iOS Info.plist (from earlier)
- Added `SCSDKRedirectUrl` key with value `campuslink://snapkit/oauth2`
- Added `campuslink` URL scheme to `CFBundleURLSchemes`

### 4. app.json (Expo config)
- Added `SCSDKRedirectUrl` to infoPlist
- Added `CFBundleURLTypes` with `campuslink` scheme
